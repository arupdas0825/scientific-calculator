# Scientific Calculator

A lightweight, browser-based scientific calculator built with plain HTML. This project provides an interactive user interface for performing a wide range of mathematical calculations directly in the browser, making it easy to run locally or embed in webpages for educational and practical use.

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari, etc.)
- No server or build tools required

### Run locally
1. Clone the repository:
   git clone https://github.com/arupdas0825/scientific-calculator.git
2. Open the calculator:
   - In your file explorer, open the repository folder and double-click the main HTML file (e.g., `index.html`), or
   - In your browser, use File → Open File and select the HTML file.

The calculator should load and be ready to use.
