# Features

## Advanced Scientific Functions

- Trigonometric operations
  - `sin(x)`
  - `cos(x)`
  - `tan(x)`

- Inverse trigonometric functions
  - `asin(x)`
  - `acos(x)`
  - `atan(x)`

- Logarithmic calculations
  - Natural logarithm `ln(x)`
  - Base-10 logarithm `log(x)`

- Power & root operations
  - Exponents
  - Square roots
  - Factorials

- Mathematical constants
  - π (Pi)
  - Euler's Number `e`

- Complex number support
  - Imaginary unit `i`
  - Real & imaginary calculations

Clone the repository:

```bash
git clone https://github.com/arupdas0825/scientific-calculator.git
```

Open the project folder:

```bash
cd scientific-calculator
```

Run locally using VS Code Live Server or simply open:

```bash
scientific-complex-calculator.html
```
